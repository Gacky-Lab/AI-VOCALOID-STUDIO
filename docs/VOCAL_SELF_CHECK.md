# 歌唱版ごとの制作自己チェックシート

担当者は作業開始時に本表を版ごとに複製し、原詞・原唱・直前の採用版・今回の譜面と音源を特定する。各行に「判定／証跡のパス／対象数・評価数・欠測数／未解決の時刻と次の確認」を記入する。測定値を取れた段階は実測済み。達成基準を確認した行だけ合格にする。

| 確認項目 | 必要な証跡 | 今回の判定・証跡・残件 |
|---|---|---|
| 1 原詞と素材 | 原曲ID、原詞、歌唱・伴奏の版、尺、時刻原点、原詞と読みの対応 | 未検証 |
| 2 歌詞を歌えているか（Q01） | 全モーラの割当。実際のドライ音声に対する音声認識または強制アライメントと試聴。脱落・重複・促音・撥音・無声化は時刻つきで記録 | 未検証 |
| 3 全曲の採譜と発声 | 5 msの原唱・直前版・今回版でF0、入り、持続、減衰、切れ。推定窓、欠測、有効母数。元の詞と対応するMIDI・Song IR・VPRX | 未検証 |
| 4 隣り合う音の連結（Q02） | 全境界を列挙。谷が取れない連音、短音、休符の除外にも確認先を付ける。修正時は左右の音長、前の母音と次の子音、意図した休符を再確認 | 未検証 |
| 5 フレーズと旋律（Q03） | 歌詞のまとまり、拍、同じサビ、伴奏、原唱の局所スペクトルを照合。極端な跳躍、短音の連鎖、音の詰まりはフレーズ単位で採否を記録 | 未検証 |
| 6 再合成と回帰検査 | 採用譜面を実機で再合成。直前版と同じ条件で対象・隣接音・全曲を再測定。改善・悪化を併記。音声変更後は旧版の判定を引き継がない | 未検証 |
| 7 表とファイルの同一性 | 最新版のExcelを再読込してCSVと全行照合。版、ハッシュ、候補・見送り、欠測を記録 | 未検証 |
| 8 ミックスと納品物（Q04–Q09） | 前後の声量、4帯域、同期、異常音、クリップ、原唱残留、編集用譜面、最終音声・字幕・口形を用途に応じ検証 | 未検証 |
| 9 最後に一曲として聴く（Q10） | 原唱・旧・新を音量一致で比較。指摘箇所は前後のフレーズを含め、声単独と伴奏入りで試聴。曲頭・中盤・終盤を含む通し試聴の版・判断者・残件 | 試聴承認待ち |

短音の長さだけで発音の良否を決めない。境界が測れない箇所には、原唱の休符・連音として妥当、実音での再確認待ち、局所修正して再測定などの処置を書く。1モーラでも聞き取り不明のままならQ01は保留。全行を確認し、人の承認を受けてから完成と報告する。途中共有には未検証・不合格・試聴承認待ちを明記する。
