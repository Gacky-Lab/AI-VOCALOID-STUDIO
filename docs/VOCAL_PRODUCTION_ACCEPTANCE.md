# 原唱WAVからVOCALOID歌唱を作るときの必須工程

原唱を採譜して歌い直す案件に適用する。担当者は各版について下表の「証跡」を記録する。試作途中の共有は可能。完成報告には各工程を **実測済み・不合格・未検証・試聴承認待ち** のいずれかで記載する。対象外は理由と依頼範囲を記録する。

| 順 | 実施すること | 次工程に渡す証跡 |
|---|---|---|
| 1 | 原曲ID、原詞、歌唱・伴奏ステム、尺、サンプルレート、曲頭を照合する。原本を保管し、別の版番号で作業する。 | 入力一覧、原詞と時刻付き歌詞の対応、権利・公開範囲 |
| 2 | 原唱の有声区間を採譜する。歌詞、読み、促音・休符、音素、音符長、音符内ピッチを対応付ける。 | MIDI、スキーマ検証済みSong IR、編集可能な譜面、低信頼箇所 |
| 3 | 指定歌手で譜面を開き、曲頭を揃えたドライ歌唱を書き出す。 | 歌手・エンジン・版、修正前の譜面と歌唱WAV |
| 4 | 原唱と合成音を全曲 **5 ms間隔** で照合する。入り・持続・減衰・切れ、隣接音の谷、伴奏中の聞こえ方を分けて調べる。 | 原唱・合成のF0（Hz）、時刻、使用窓・推定法・有声条件。無声・推定不能は空欄 |
| 5 | 音域逸脱は基音・倍音・前後の旋律を照合する。反復サビでは同じ歌詞を位置合わせし、各出現箇所の原唱スペクトルでも裏付ける。発音境界の移動は両側の音符長・休符を確認する。 | 音符番号、歌詞、候補と根拠、採用・保留理由。曲固有の探索帯域や閾値を記録 |
| 6 | 採用箇所を譜面で修正して実機再合成する。直前版と同じ時刻・測定条件で再測定する。修正対象の改善と全曲で悪化した指標を併記する。 | 修正後VPRX・MIDI・歌唱WAV、音符別の前後差、欠測数・評価母数 |
| 7 | **納品する歌唱版のExcel監査表（.xlsx）を生成し、保存後に再読込する。** CSV作成、ブック生成、ブック検証は別々に記録する。 | 下記の3表、再読込結果、入力CSVとブックの版・ハッシュ |
| 8 | 伴奏と歌唱を同じ窓で測る。250–700、700–1500、1500–3000、3000–5500 Hzの4帯域と前後フレーズの声量を検査。残響・EQ・マスター処理を記録し、完成ファイルを復号する。 | 帯域別比較、原唱残留候補、無音・クリップ、LUFS-I・True Peak、冒頭・中盤・終盤の同期実測 |
| 9 | 原唱・直前版・新版を同一区間、同一比較音量で試聴できるようにする。MVは原詞全文、字幕・口形・映像尺・最終音声を照合する。 | 比較音源と順序、最終ファイルの版、Q01–Q10の結果、本人の試聴判断 |

## Excelの受入条件

1. **全曲時系列表**に曲頭からの秒、音符番号・歌詞、原唱Hz、修正前Hz、修正後Hzを置く。正しい直前版を使用する。0秒始まり・5 ms刻み・終端を含まない場合、期待行数は音声長を5 msで割って切り上げた値。間奏も保持する。
2. **音符別表**には修正前後の時間範囲、入り・持続・語尾の音高差（cent）を記録する。**候補表**には変更した音と見送った音の両方、元音高、候補、実測・判定根拠を記録する。
3. 再読込したブックについて全行の時刻、重複、欠落、Hz値、空欄を元の測定表と照合する。音符別表・候補表の件数を確認する。版違い、行不足、空欄のゼロ置換があれば再生成する。
4. 歌唱の作り直し、音符・タイミングの変更、元ステムの差し替えでは、依存する測定・Excel・比較試聴・ミックス・MVの検証を更新する。映像だけの変更で音声を流用する場合は、その同一性を確認する。

標準レイアウトではシート名を「全曲5ms」「音符別」「倍音候補」、見出しを4行目とする。「全曲5ms」のA列は秒、D列は原唱Hz、E列は直前版Hz、F列は新版Hz。各版の入力CSV列は `s,reference_Hz,miku_Hz`。次は192.2秒、588音、サビ7回×12音を検査した場合の例。件数は案件ごとに譜面・尺・候補一覧から決める。

```sh
python tools/verify_frequency_book.py audit.xlsx before.csv after.csv --frames 38440 --notes 588 --candidates 84
```

検証器は全時刻・3系列のHzと欠測・各表の行数を照合し、成功時に各ファイルのSHA-256を返す。不一致は異常終了する。音符別判定の音楽的妥当性は別途確認する。

5 msは推定値を読む刻みであり、音程の正解や音響的な時間分解能を保証しない。別声部や倍音の候補、原唱の残留、歌詞の聞き取りは人間の試聴判断を残す。ローカルでの検証と、素材をGitHub・YouTubeへ公開できるかは別々に記録する。
