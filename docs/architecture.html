04品質保証・受入試験（目標）

歌詞未割当・意図しない反復0 件
明瞭な発音境界の誤差≤ 100 ms
安定音のピッチ中央値差≤ 50 cents
曲頭・中盤・終盤の同期≤ 50 ms
True Peak / 初期マスター目標≤ −1 dBTP
総合試験・無人完了目標19 / 20 曲以上
  • 破損・全無音・意図しないクリッピングなし
  • 元歌声残留候補と異常音を検査・試聴
  • 全20曲の制作承認・楽譜/RPP再読込

すべて受入目標。UNKNOWNは自動合格不可。手動代替と無人完了は別集計。

05開発ロードマップGo / No-Goによる段階移行

PHASE 0接続・歌唱試験15秒素材・3回独立出力
PHASE 1歌唱解析歌詞付き楽譜
PHASE 21曲のボカロ化Original成立
PHASE 3調声・同期部分修正と再検査
PHASE 4VST3・REAPERHybrid成立
PHASE 5品質・異常復旧検査器・途中再開
PHASE 6–720曲受入・運用定型ワンクリック制作

Phase 0：無人歌唱が不合格なら完全無人化を保留。純正音源の手動MVPは継続可能。
