# 原唱WAVから編集可能な初音ミク譜面を作る

2026年11月27日。Gacky-Lab の「We Flowed Past the Morning」で行った、英語の歌声の採譜、VOCALOID7での再合成、比較試聴の制作記録。実行環境はWindows、Codex、ローカルMCPブリッジ、認証済みの初音ミク V6 ORIGINAL / SOFT。公開リリースの対応範囲は [v0.1.0-alpha](../../releases/v0.1.0-alpha.md) を参照。

## 制作工程

| 工程 | 操作と判断 | 次工程に渡すもの |
|---|---|---|
| 素材と時間軸 | 同じ曲のボーカル・伴奏ステム、原詞、時刻付き単語を用意。分割された単語と複数音節を原詞と突合する。 | 曲頭を共有する48 kHzステレオ素材と歌詞対応 |
| 採譜 | 原唱から10 ms刻みで自己相関音高を取り、連続した有声音を音符化。母音の不必要な再発音を統合し、残すべき音高変化は音符内に記録。 | 572音符から536音符へ整理。途中版で9,773点のピッチ曲線。MIDIと歌詞・音素・直接ピッチ付きVPRX |
| 合成 | VPRXをMCPブリッジで開き、初音ミクの歌声を48 kHzで書き出す。音符の位置、長さ、音高、歌詞、音素、強弱を別々に編集する。 | 同じ開始位置のミク単独歌唱と編集用譜面 |
| 音節と語尾 | 原唱と合成音の母音エネルギーの谷、持続部、減衰、次の音の立ち上がりを比較。再合成した結果から音符長とDynamicsの効きを校正する。 | 語ごとの入り・伸び・切れ、休符、音量曲線 |
| 音域の再検査 | 単語の頭・続き音、曲の前半・後半を通して全音符を検査。複数の音が重なる区間では基音と倍音の支持を確認する。 | 536行の周波数監査記録 |
| 伴奏内の照合 | 250–700、700–1,500、1,500–3,000、3,000–5,500 Hzの4帯域で、伴奏に対する声のエネルギー比を比較。短い共通残響で声と伴奏の距離を合わせる。 | 伴奏・ハモリ込みのフルミックス |
| 全曲の最終確認 | 修正音を前後のフレーズに戻し、声量の突出、音程の渡り、子音の明瞭さ、語尾の余白を確認。変更前後を同じ試聴音量で比較する。 | 全曲WAV、短い比較音源、試聴判断 |
| MV | 原詞111行を譜面の単語時刻と対応させ、歌詞と音符表示を同期。横顔の一枚絵、歌詞の動き、光の粒を合成。 | 1920×1080、25 fps、5,030フレーム、201.2秒のMV |

本事例の時刻変換は120 BPM・480 PPQ・パート開始0で、960 tickが1秒。他曲ではテンポマップとパートの開始位置を読み直す。原唱・伴奏の位相と開始位置がずれると周波数以外の比較も崩れる。音声区間が短い場合や無声子音では、音高を欠測として扱う。

## どこで手法を変えたか

- **単語が詰まる。** 7秒付近の “Golden” では最初の音節から次に渡る谷が原唱より100 ms遅かった。隣接音の長さを再配分し、再合成後の差は20 ms。同じ工程で全曲51境界を修正し、再測定できた48か所の中央値は40→10 ms。谷は音響上の代理指標で、発音の主観評価は別に行う。
- **単語の途中で音域が落ちる。** “another” の最後はMIDI 71から53に落ちていた。原唱の基音と倍音が直前の音域を支持したためMIDI 72に直し、再合成で173.7→519.9 Hzを確認した。
- **単語の頭でも同じ問題が起きる。** “ends” は独立した単語だったため、続き音のみを見る検査から漏れた。約349→393 Hzの原唱の推移を譜面に戻した。その後の全曲監査で、55.532秒の “flowed” も発見。原唱候補783.7 Hz、ミク261.3→782.3 Hz。歌詞の一致だけを根拠に別の出現箇所まで一括置換しない。
- **単独歌唱と完成ミックスで印象が変わる。** “another” では入りから語尾の強さの差が単独歌唱で改善しても、完成ミックスでは母音の途中が入りより約3 dB強くなった。試聴を受けてその局所区間を約−0.3 dBに調整した。試聴で選んだ48–53秒を以降の比較の基準にした。

## 全音符の周波数監査を追試する

1. VPRXの音符順に番号を振り、音符内の8–83%を主に12.5 ms間隔で調べる。48 kHzの原唱をモノラル化し、3,072サンプルのHann窓と16,384点FFTを使用する。
2. 基音候補と第2倍音を組にして評価する。今回の基音探索は約103–879 Hz。候補の中央値から2.6半音以内のフレーム数を調査フレーム数で割り、支持率とする。この値は主旋律である確率を表さない。
3. 支持フレーム3以上、支持率64%以上、候補と譜面の差6半音以上を条件とする。さらに支持フレームの78%以上で基音強度が既存音域の3倍超かつ競合候補に対するスコア比が1.25超のとき、音符と曲線を書き換える。試聴承認区間は保護する。しきい値は本曲の実験値。
4. 再合成したミクは自己相関（10 ms刻み、100–900 Hz）で測る。音符内12–80%の有声フレーム中央値をHzに換算。2フレーム未満は欠測。原唱側の倍音推定とミク側の自己相関は異なる測定。空欄を0 Hzとして集計しない。
5. 検査結果を音符番号・開始時刻・原唱候補Hz・ミク修正前後Hz・支持率・判定の表にし、行単位で照合する。分類は修正12、近接338、要確認186。近接は修正前のミクと支持された候補との差が1半音未満。要確認には短音・重唱・推定不一致が含まれる。表の番号は1始まり。

## 全曲に戻してから判断する

音高検査後に「修正音だけ力んで聞こえる」という試聴意見があったため、最終工程を追加した。原唱と伴奏のステム、現在の完成ミックス、同じ空間処理を施した伴奏を同一時間軸に置く。後者をミックスから引いて得た声にはハモリ・残響も含まれる。

- 20 ms窓のRMSから、ミク側と原唱側それぞれの「声−伴奏」のdB差を求める。この2つの差を時系列にする。
- 各修正音中央の前後2.5秒から有効な歌唱窓を採用する。修正音周辺は基準から除外。近傍中央値に対し、その音の中央12–88%がどれだけ突出または埋没しているかを測る。
- ずれの70%を戻す方向へ完成ミックスの声成分を調整する。1音あたり±3.8 dBを上限とし、入口・出口で連続的に元のゲインへ戻す。元譜面の音高を維持する。書き出した全曲を、短い比較区間と通しの双方で確認する。

| 最新の文脈補正 | 補正前 | 補正後 |
|---|---:|---:|
| 修正12音の近傍基準からのずれ（絶対値中央値） | 4.65 dB | 1.40 dB |
| 全曲の有効歌唱窓での声−伴奏（中央値） | −2.29 dB | −2.36 dB |

55.532秒の “flowed” は音高を維持し、ミックス上で約2.2 dB引いた。これは音量・伴奏との関係を示す測定。滑らかさ、歌詞が伝わるか、旋律の選択、最終的な好みは人間の試聴承認待ち。

## 再現性の範囲

公開範囲は設計手順、測定方法と代表的な実測結果。全音符の監査表と区間別ログはローカルに保存した。別の環境で同じ歌唱波形を再生成するには、許諾された元ステム・時刻付き歌詞・譜面、対応する初音ミクのライセンスとVOCALOIDエンジンが必要。本曲はローカル実機で再合成・書き出し済み。公開パッケージだけでの端から端までの再生成、別曲への汎化、プロとの同条件ブラインド比較はいずれも未検証。
