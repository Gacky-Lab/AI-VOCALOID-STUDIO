# 「キミガオトす星のカケラ」制作設計と検証範囲

## ローカル設計項目の追補：歌詞と音符の境界を全曲で照合する

- [ ] 原唱、歌詞、譜面、再合成した主旋律を曲頭から同期する。対象の全音符に番号を振り、前の語尾・対象の子音と母音・次の語頭を同じ時間軸で並べる。
- [ ] 休止の有無にかかわらず、原唱の母音が続く途中で譜面が次音へ進む箇所、前音が次の子音に食い込む箇所、次の母音が短くなる箇所を調べる。語中・語境界・休符・フレーズ末を区別する。
- [ ] 原唱の母音の入り・伸び・減衰・切れ、安定部の音高、後続語の入りを基準に配分を決める。無声子音やブレスには音高を割り当てず、分離残留や対応の曖昧な箇所は要試聴と記録する。
- [ ] 再合成後、対象と前後それぞれの誤差を再測定する。前後を含む同一区間を原唱・旧版・新版で音量をそろえて比較し、伴奏内での聞き取りとフレーズ全体の流れを確認する。
- [ ] 完了報告には走査した配置、対象数、除外理由、採用数、未検査の配置、試聴判定を記載する。特定区間の1 ms表から全曲の合格を推定しない。

## 追補：「とって」の音域と促音を別々に検査する

- [ ] 一音だけ低く落ちて次で戻る配置を全曲で抽出し、休符の有無を問わず確認する。母音の安定部で推定した音高について原候補・半分・倍の周波数を比較し、倍音の並び、前後の旋律、同じ歌詞が繰り返される箇所を照合する。根拠が分かれる場合は原譜を保ち、別名の試聴候補を作る。自然な跳躍もあるため、一律に平滑化しない。
- [ ] 促音を含む語では、先行母音の終端、閉鎖区間、次の子音の開放と母音の開始を別々に記録する。「とって」は「に→と→っ→て」まで聴く。「っ」は有声音符の採点から漏れるため、無音・減衰の位置と長さを別に検査する。
- [ ] 再合成した歌声で母音の実音高と閉鎖の位置を再測定する。1オクターブの取り違えを全曲平均に埋めず、対象語ごとに結果・不確かさ・試聴判定を残す。

今回の版履歴（音符番号138 / 503）では、初稿の音高がMIDI 53 / 52、直前版が53 / 53、修正版が65 / 65。初稿の生成処理は歌詞時間をモーラに重み配分し、有効な推定音高の中央値（欠測時は補間値）を丸める。「っ」は重み0.55の時間を確保して発音用音符の生成をスキップする。原唱のどの成分が低い推定を生んだかは未確定。37秒台では新版が「と」を短縮して「て」の入りも移動した。後半は「と」の音高のみ修正。音域・促音の新項目を使った全曲自動検査は未実装。試聴は37秒（制作時のローカル記録 `../kakera-totte/compare.wav`）と後半（制作時のローカル記録 `../kakera-totte/reprise.wav`）、修正版は譜面（制作時のローカル記録 `../kakera-totte/final.vprx`）とフルWAV（制作時のローカル記録 `../kakera-totte/full.wav`）。

## 公開候補の仕上げ：語頭から次の語への受け渡しまで検証する

1. 聞き取りの指摘を曲頭からの時刻・歌詞・音符番号に対応させる。原唱・旧版の主旋律・伴奏込みで、母音の欠落、音域の取り違え、局所的な声量低下を分けて記録する。
2. 休止の有無にかかわらず全譜面の隣接音を走査する。本曲では、前後に逆方向の8半音以上の跳躍がある音、次音が推定母音末より45 ms以上早い境界を試聴候補にする。これらの値は候補抽出用で、採否には原唱を使う。
3. 反復句の安定母音の周波数と倍音を照合して音域候補を選び、各出現位置の原唱から「か・が・や・く」の個別の長さと音高曲線を取り直す。歌詞が同じでも発音時刻をコピーしない。F0推定値と主旋律候補が異なる母音は測定表に残す。
4. 「ぼくに」のような連音では3母音それぞれの原唱・旧版・新版のレベルを同じ窓で測る。音符境界を直してから、母音が伴奏内で聞こえるよう、局所の声量を滑らかに調整する。
5. 再合成後は対象語の最後の母音が狙った音高をいつ離れるか、次の母音が予定した音高に着くかを調べる。エンジンが譜面の境界より早く次音へ滑る場合は、前音の持続と次音の入りを一緒に調整して再合成する。指摘箇所だけを強くする変更は前後の母音も比較する。
6. 旧版と同じ伴奏・マスター条件でフルWAVを書き出し、尺、ピーク、修正範囲外の波形を照合する。原唱・旧版・新版を同音量で提示し、聞き取りの承認は測定結果と分けて記録する。

今回の証跡：全588音の候補抽出（制作時のローカル記録 `../kakera-phrase-release-02/all-boundaries.csv`）、原唱・旧版・新版の母音別測定（制作時のローカル記録 `../kakera-phrase-release-02/vowels.csv`）、修正版譜面（制作時のローカル記録 `../kakera-phrase-release-02/final.vprx`）、比較試聴（制作時のローカル記録 `../kakera-phrase-release-02/compare.wav`）、フルWAV（制作時のローカル記録 `../kakera-phrase-release-02/full.wav`）。

## 25秒の連音と声の広がり

「君だけが知ってる光」は、「き・み」で時間を使いすぎると後続の「だ・け・が」にしわ寄せが出る。「し」の持続、「っ」の閉鎖、「て」の入り、語末「り」の持続まで原唱の同じ時間軸で確認する。各音の基準音高は原唱母音のスペクトルも参照し、音量の埋め合わせに先立って11音の配置を調整した。

広がりは声と伴奏を分け、左右差成分と中央成分のエネルギー比で原唱との隔たりを測る。今回は伴奏を基準に保ち、主旋律に既にある左右差成分のゲインを全曲で調整した。中央の歌詞の明瞭さ、モノラルでの再生、ステレオの自然さは別々に確認する。左右差の比が一致しても同じ残響時間・定位にはならない。

再検証用：11音の母音比較（制作時のローカル記録 `../kakera-hikari-space/vowels.csv`）、原唱・直前・新版の試聴（制作時のローカル記録 `../kakera-hikari-space/compare.wav`）、譜面（制作時のローカル記録 `../kakera-hikari-space/final.vprx`）、フルWAV（制作時のローカル記録 `../kakera-hikari-space/full.wav`）。

## 反復検証の採否と停止条件

候補の発見と採用を別の工程にする。音符の跳び方と母音スペクトルから候補を作り、原唱・旧版・実機再合成の基本周波数を同じ母音窓で比較する。旧版が原唱312 Hzに合っていても倍音から624 Hzを選べるため、倍音と隣接音だけを根拠に採用しない。この版では原唱と候補音の差85 cent未満、再合成と候補音の差100 cent未満、旧版からの改善150 cent超、音量誤差の悪化1 dB未満を要求した。曖昧な推定は保留する。

境界を動かした場合は、先行母音の末尾と後続母音を個別に採点する。声量の反復では母音内を交互の10 msブロックに分け、片側で補正量を決めて他方で改善を検査する。これは同じ録音内の局所検証である。前後を滑らかに接続し、1回の変更は最大1.15 dB、累計は最大3.5 dB。新しい採用がゼロになったら当該方式を停止し、実際に書き出す信号でも再測定する。上限を緩めて自然さの点数を上げない。機械測定の収束と作品の公開承認を分ける。

今回の実行は588音・587境界を走査。最終音高候補6件中1件、境界候補1件中1件を採用。声量の採用回数は65→22→15→0（異なる母音は65）。対象母音の検証ブロック全体で平均音量誤差4.44→3.47 dB、丸めた記録上の悪化0件。25〜27.5秒の完成波形は直前版と一致。原唱を含むブラインド試聴や全歌詞の聞き取り試験は未実施。

記録：音高の採否（制作時のローカル記録 `../kakera-context-loop-02/pitch-acceptance.csv`）、境界の採否（制作時のローカル記録 `../kakera-context-loop-02/timing-acceptance.csv`）、反復履歴（制作時のローカル記録 `../kakera-context-loop-02/iterations.csv`）、最終母音検査（制作時のローカル記録 `../kakera-context-loop-02/verified.csv`）、採用譜面（制作時のローカル記録 `../kakera-context-loop-02/timing.vprx`）、フルWAV（制作時のローカル記録 `../kakera-context-loop-02/full.wav`）。

## 完成歌唱の音素境界を使う反復

基準は直前の採用ミックスと対応する譜面。既知歌詞から行別に作った同一の音素列で原唱と合成主旋律を照合する。基準版の主旋律は直前のプリマスター差分から復元する。照合は16 kHz・10 msフレームで全行に実施し、音素列が一致することを確認してから時刻を比較する。これは歌詞を与えた強制アラインメントで、未知の歌詞を正しく聞き取れたことを示す検査ではない。

1. 同一行の隣接母音で、次の母音開始が原唱より50～160 msずれ、前の母音末も同方向に35 ms超ずれる箇所を選ぶ。譜面との差、音長、既存休止を確認し、単一パスでは近接候補を分ける。
2. 2音の境界を実測ずれの65%とその半分だけ動かす2案を作る。両端の時刻と音高を保ち、ピッチ曲線の時間位置を音長に合わせる。各案を同じ初音ミクで再合成する。
3. 合成音の中央成分を区間両端45 msでクロスフェードし、既存の左右差・伴奏を維持する。原唱との局所的な音量差に上限付きの補正を適用する。2案とも完成版と同様の主旋律に組み込んで再照合する。
4. 「前母音の末尾」と「次母音の開始」の絶対誤差の平均が15 ms以上減ること、隣接母音の平均悪化が7 ms以内、対象2音の外側の境界誤差の悪化が10 ms以内を確認する。対象母音の音量誤差の悪化は各1.25 dB未満、原唱からの音高誤差の悪化は各50 cent以下。測定不能な候補は保留する。両案合格なら境界誤差が小さい案、同値なら小幅案を選ぶ。
5. 採用箇所だけを混ぜた状態で全行を再照合する。文脈が変わって判定が崩れた箇所を戻し、再び照合する。次のパスではその版を基準にし、前回近接していて試せなかった境界も検査する。棄却済みの境界は同じ手法の再試行から外す。後続パスでは全曲の音素開始誤差の平均も0.01 ms以上改善した場合に版を採用する（集計上の条件であり個別時刻の精度ではない）。
6. この候補生成法で未評価の対象が尽きたら終了し、版・候補・採否・全音素の時刻を記録する。最終WAVと原唱・直前版の比較を出力する。技術検査の終了と公開承認は別項目。

再現用：抽出（制作時のローカル記録 `../kakera-phone-loop/plan.py`）、各案の採否と組み合わせの再検査（制作時のローカル記録 `../kakera-phone-loop/verify.py`）、反復と停止の条件（制作時のローカル記録 `../kakera-phone-loop/repeat.py`）、各パスの実行記録（制作時のローカル記録 `../kakera-phone-loop/progress.json`）、採用した全変更（制作時のローカル記録 `../kakera-phone-loop/adopted.csv`）。各パスの trials.csv に棄却案を含む比較、decisions.csv にそのパスの決定を保存する。

## 伴奏に隠れる子音の検査

音符を移動する前に、同じ時刻に主旋律と伴奏が鳴ったときの帯域別レベルを確認する。既にタイミングが合っていて、伴奏に隠れる子音にはミックスで対処する。基準は直前の「kakera-phone-release」。この工程ではその譜面を使用する。

1. 原唱と合成主旋律の子音境界の共通部分を抽出する。共通部分が32 ms以上、各推定子音長が240 ms以下の区間で、摩擦音等には2.2～7.6 kHz、その他の対象破裂音には0.9～4.4 kHzを使う。
2. 交互の5 msブロックの一方で、原唱より合成主旋律が3 dB以上弱く、伴奏との差が+1 dB以下、原唱の対象帯域が−48 dBFS以上であることを確かめる。いずれかを満たさない子音は保留する。
3. ミクの既存の中央成分からその帯域だけを取り、子音内で滑らかに足す。1、2、3 dBの上限を試し、原唱との差を超えて足さない。別の5 msブロックで帯域レベル誤差が0.45 dB以上減った音だけを候補に残す。
4. 行ごとに伴奏を含む旧版・各候補を同じ日本語認識器で比較する。旧版より文字編集距離が増える案を落とす。残った案のうち文字誤りが少なく、同値なら対象帯域の誤差が小さい案を選ぶ。全曲に組み込んでマスター処理した後に再認識し、悪化した行を旧版に戻して再検査する。
5. 出力は歌詞・音符付きの既存譜面、ミックスの再現スクリプト、全試行の採否、最終WAVを組にして管理する。この検査は子音の聞こえやすさの代理指標であり、語全体の自然さ、声の魅力、作品の公開承認は個別に記録する。

検証：処理と判定式（制作時のローカル記録 `../kakera-consonant-space/run.py`）、全試行（制作時のローカル記録 `../kakera-consonant-space/trials.csv`）、最終音源での認識結果（制作時のローカル記録 `../kakera-consonant-space/validation.csv`）、採用子音（制作時のローカル記録 `../kakera-consonant-space/consonants.csv`）、行ごとの最終採否（制作時のローカル記録 `../kakera-consonant-space/delivery.csv`）。

## フレーズ内の強弱と聞き取りを別々に検査する

比較単位は歌詞の一行。原唱の語の強調を推定する手がかりとして、対応する母音どうしの相対レベルを用いる。意味上のアクセントと音量が常に一致するとは限らないため、これはフレーズ表現の一側面の検査として記録する。出発点は「kakera-consonant-space」のプリマスターと「kakera-phone-release」の譜面。

1. 原唱・ミクで母音を別々の発音境界に合わせて切り出す。双方60～650 ms、両端のずれ115 ms以内の母音を使う。母音の前20%と末尾18%を除き、レベルが十分な区間を選ぶ。4母音以上そろった行で検査する。
2. 対応する母音ごとの原唱とミクのレベル差から、その行の差の中央値を引く。これで、行全体を大きくする効果と、その行の中でどの母音が強いかを区別する。5 msブロックを交互に分け、片側で補正を求め、もう片側で誤差を測る。
3. 相対レベル誤差が平均1.4 dB以上なら45%・80%の2案を作る。原唱に対して強すぎる母音は抑え、弱い母音は持ち上げる。各母音の中央を滑らかにつなぎ、320 msを超える空きでは中央に向けて補正をゼロに戻す。ミクの中央成分だけを補正し、原則として行全体の声量を保つ。
4. 平均相対誤差が0.35 dB以上縮まり、行全体の声量差が0.35 dB以内、個々の母音の相対誤差の悪化が1.25 dB以内の案を残す。伴奏込みで歌詞なし認識を試し、編集距離の増えた案は落とす。採用順は認識誤りが少ない案、次に相対レベル誤差が小さい案。
5. 全曲の最終マスターで認識を繰り返し、悪化した行を戻す。完成WAVの尺とピークを照合する。同音量の原唱・旧版・新版を出力し、自然さは聴き比べで判断する。譜面の音符・歌詞は既存版を使用し、今回の表現の差はミックスで再現する。

## 歌詞の間隔を、連続する3母音の時間配分で検査する

基準版は kakera-pyin-release。歌詞の文字位置と音符を既存のモーラIDで結び、同一行の隣接3母音について、前→中央と中央→次の開始間隔を原唱・ミクで別々に計算する。各間隔の「ミク−原唱」が逆符号なら、一方に時間が寄ってもう一方が詰まった候補である。これにより行全体の一定の遅れとは区別できる。母音開始は既知の歌詞を与えた照合器の推定であり、人間が知覚するアクセントの位置とは限らない。

1. 両側の間隔の差が各35 ms以上、片側が65 ms以上あり、原唱とミクの両側の間隔が55～520 msの箇所を抽出する。既存休符が18 tickを超える場合、中央の譜面開始と参照の母音開始が180 ms以上違う場合はこの手法の対象外。原詞表記、行番号、音符番号、左右それぞれの符号付き偏差を保存する。
2. 左右の偏差の差の半分に0.72を掛け、最大95 msに制限する。中央音の開始を移し、直前音と中央音の長さに逆向きの変更を加える。両端と既存の休符長は固定し、ピッチ曲線の時間位置を音長に合わせ直す。音高と歌詞は維持。通常幅・半幅を同じ初音ミクで実機合成する。近接する候補は分離して検査する。
3. 再合成後、2間隔の平均絶対誤差が15 ms以上縮まり、各側の悪化が5 ms以内か確認する。隣接母音の開始・終了誤差の平均悪化は7 ms以内、対象2音の外側端は10 ms以内を基準とする。各対象母音のレベル誤差の悪化1.25 dB未満・音高誤差の悪化50 cent以下とし、欠測は採用しない。
4. 改善した候補だけを元の主旋律へ区間接続し、伴奏・左右差を継承する。全曲再照合後、採用行の完成ミックスを歌詞を渡さない日本語ASRにかける。文字編集距離が増加した行は変更を戻し、最終主旋律で間隔を再測定する。残った候補、推定器による誤差、試聴承認の有無を分けて記録する。

## 「光を追いかけて」「見つけた」「新しい」の調整

前版は kakera-three-words/round2/full.wav。全曲の原詞から2回の同一フレーズと、ほかの「見つけ」4回を抽出した。「を」と「追」の連続母音、母音「い」の居場所、/k/ /t/ の立ち上がり、「み・つ・け」の長さ、語尾と次の語の接続、前後に対する「新しい」の強さ、反復での一貫性を別々の検査項目とする。これは総合評価の残り7点に機械的な配点を与えるものではない。

## 原唱の反復と母音を用いた音高修正

「追いかけて」「見つけた」「新しい」の前半と後半で同じ歌詞の母音を対応づけた。原唱の母音中の複数位置で第2–7倍音と倍音間のエネルギー差を測定。両出現で支持され、かつ当該区間で現行音符より支持の強い候補音高を抽出した。反復で旋律が違う場合は共通音高を強制しない。今回は特定の2フレーズだけを対象にした。原唱ステムの残留音や倍音の解釈には不確実性がある。

同一抜粋の原譜、音高のみ変更した譜面、異常なピッチカーブも変更した譜面をVOCALOID7で再合成した。原唱倍音での推定とレンダー後のPraat自己相関の両方を確認。候補13音中12音を採用。後半「新しい」の語尾「い」は、旧レンダーが既に推定音高とほぼ一致しており、候補では余分に低下したため原譜を維持した。

「ら」は前半でピッチカーブが音符内で約22半音動いていた。原唱の「ら」の母音は前半50 ms、後半60 msであり、後続の「し」の摩擦区間まで母音の判定に含めない。全音符窓での判定と、原唱側で確定した母音時間窓での再検査を区別する（今回、全音符窓の試験後にこの判定を追加）。母音窓で推定音高の周波数の÷1.09～×1.09の範囲に入る測定フレームは、前半0→100%、後半0→92%。いずれも短い局所の値であり、試聴点への換算は行わない。音符、声量、伴奏のどれが原因かを分け、音符番号だけで直らないときはdirectPitchesの開始・終端・変動幅まで見る。

既存素材を用いた新規兄弟フォルダでの再現順は prepare.py、synthesize.py（controlとpitch）、curve.py、synthesize.py（curve）、releaseサブフォルダの作成、release.py、check.py。reconstruct.pyで前版の検証区間のステムとゲインを再構成する。既存の前版素材一式も必要。完成WAVは以前の処理を引き継ぐ局所ミックスであり、VPRX単体の書き出しとは異なる。
