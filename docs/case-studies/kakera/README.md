# 「キミガオトす星のカケラ」の隣接音と区間試聴

2026年11月27日。原唱を基準に、隣り合う歌詞の発音間隔を調整すると、10秒付近の「君はひとつ見つけたね」が聞きやすくなるかを検討した。原唱・直前の初音ミク・修正後の初音ミクを同じ7〜12秒で比較した。

## 測定結果

既知の歌詞を用いて音素境界を推定し、隣り合う音符の末尾音素の開始時刻の差を比較した。「見つけたね」の「つ→け」は原唱160 ms、直前310 ms、修正後160 ms。指摘フレーズの10境界で原唱との絶対誤差の中央値は60 msから15 msになった。全曲587境界では60 msから50 msになり、うち47境界では誤差が40 ms以上増えた。

## 制作者による試聴

再生順を原唱＋伴奏、直前版、修正版とした16秒の比較音源に対する制作者の回答は「さいごのやつのほうがましです」。このため、当該5秒区間の次回調整の基準には修正版を採用する。1名の順序を明示した比較であり、どの変更が選好の原因かは特定できない。「ね」の母音開始は依然として原唱より80 ms早い。曲全体の自然さ、および別の歌詞「消えない光を追いかけて」の聞き取りは保留とする。

## 聴き比べと追試

[比較WAVを再生・ダウンロード](https://raw.githubusercontent.com/Gacky-Lab/AI-VOCALOID-STUDIO/main/docs/case-studies/kakera/compare-7-12.wav)。同じ歌詞と伴奏で、0秒から原唱、5.5秒から直前版、11秒から今回の修正版を再生する。各区間は5秒、間の無音は0.5秒。

リポジトリのルートで以下を実行する。Python 3.10以上の標準ライブラリだけで実行できる。

```sh
python docs/case-studies/kakera/reproduce.py
```

スクリプトは [音素境界](phones.csv)、[修正前後の譜面](score-audit.csv)、[5 msごとの基本周波数](pitch.csv) を読み、[保存した結果](comparison.json) と件数・中央値・平均・90パーセンタイル・悪化件数を照合する。境界ごとの数値は[全587境界の表](transitions.csv)で確認できる。この追試の開始点は音響測定後のCSVであり、元WAVからの音素境界推定・初音ミクの再合成は含まない。

音程変化は、原唱の各音符の末尾音素区間で、3音源とも基本周波数を取得できた5 ms点が5点以上ある場合に集計した。各音源の周波数をセントに換算して中央値を取り、隣接音への変化量を原唱と比較する。条件を満たした458境界で誤差中央値は33.46セントから27.31セントになった。音素時刻は既知歌詞を与えたJuliusの推定値で、歌詞の明瞭さは別途試聴で判断する。
